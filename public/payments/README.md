Upload your Zelle and Venmo QR images here using GitHub → Add file → Upload files.
For example: zelle-qr.png and venmo-qr.png. Use PNG/JPG/WebP, not a screenshot containing private account information.
Then edit src/payment-config.js: qrPath: '/payments/zelle-qr.png' (or the matching filename).
These images and payment details are public to customers. Do not upload banking credentials.
